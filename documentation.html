Technical User Guide & Execution Manual

Complete operational manual for configuring, building, running, and extending the Resilient UAV-MEC simulation harness in extended iFogSim2.

Overview

This repository contains the full discrete-event simulation harness for modeling collaborative aerial edge computing over disrupted disaster regions. Built upon iFogSim2 and CloudSim, it incorporates 19 custom research classes implementing rotary-wing quadrotor aerodynamics, probabilistic urban Air-to-Ground propagation, 802.11p DSRC Air-to-Air consensus gossip, and the proposed Chain-Aware CBBA protocol.

Scope Constraint: In accordance with M.Tech Semester 3 dissertation guidelines, this manual details the design, configuration, and execution of Algorithm 1 (Chain-Aware CBBA). Phase 2 runtime fault recovery mechanisms are framed as future research extensions.

System Requirements

  • Operating System: Windows 10/11, Ubuntu 20.04/22.04 LTS, or macOS (Apple Silicon / Intel).
  • Java Runtime Environment: JDK 8, 11, 17, or 21 (Adoptium OpenJDK recommended).
  • Integrated Development Environment: Eclipse IDE for Java Developers, IntelliJ IDEA, or VS Code with Java Extension Pack.
  • Bundled Dependencies: Pre-packaged in the jars/ directory (CloudSim 3.0.3, Apache Commons Math3 3.5, Google Guava 18.0, OpenCSV 5.9).
  • Plotting & Analysis: Python 3.8+ with Matplotlib and NumPy (optional, for custom chart generation).

Configure & Build

Clone the repository and import it into your workspace:

Terminal / Git Bash 
# 1. Clone the repository
git clone https://github.com/Kanchi-karthik/Resilient-UAV-Edge-Computing.git
cd Resilient-UAV-Edge-Computing

# 2. Build via CLI (compiles all Java packages into bin/)
javac -cp ".;jars/*" -d bin src/org/cloudbus/cloudsim/*.java src/org/fog/*/*.java src/org/fog/test/proposed/*/*.java

Empirical Protocols

Experiment Definitions: E1, E2, and E3

Baseline E1

Greedy Offloading

Ground devices offload subtasks strictly to the nearest physical UAV with queue space. If the buffer is full, tasks are immediately discarded. Does not consider pipeline precedence or future stages.

Baseline E2

Standard CBBA

Classical consensus bundle algorithm (Choi et al., IEEE T-RO). Multiplier is inactive (\(\gamma = 1.0\)) and pre-bid energy feasibility guards are omitted. Triggers severe task fragmentation.

Proposed E3

Chain-Aware CBBA

Our proposed protocol featuring Atomic Chain Multiplier (\(\gamma = 1.5\)) to enforce co-location, and Pre-Bid Energy Feasibility Guard (\(20\,\text{kJ}\)) to guarantee flight safety.

Core Mathematical Formulations

1. Momentum Aerodynamics & Steady Hover Power:

$$P_{\text{hover}} = P_0 + (1 + k) \sqrt{\frac{W^3}{2 \rho_{\text{air}} A_{\text{total}}}} = 79.86 + 1.13 \times 78.30 \approx 168.0\,\text{W}$$

2. Pre-Bid Energy Feasibility Guard:

$$E_{\text{est}}(j, i) = P_{\text{hover}}(t_{\text{comp}} + t_{\text{ingest}}) + P_{\text{cpu}} t_{\text{comp}} + P_{\text{comm}} t_{\text{ingest}}$$ $$\text{If } E_{\text{est}}(j, i) > E_{\text{rem}, i} - E_{\text{reserve}} \implies c_{ij} = 0$$

3. Atomic Chain Incentive Multiplier (\(\gamma = 1.5\)):

$$c_{ij} = \begin{cases} 1.5 \times c_{ij}^{\text{base}}, & \text{if } \exists k \in \mathbf{b}_i \text{ such that } k \in \text{pred}(j) \\ c_{ij}^{\text{base}}, & \text{otherwise} \end{cases}$$

Metric Definitions

  • Task Completion Rate (\(\eta_{\text{comp}}\)): Total completed subtasks divided by total generated tasks across all ground clusters.
  • Pipeline Chain Success Rate (\(\eta_{\text{chain}}\)): Percentage of 3-stage workflows where all three constituent subtasks (Ingestion, Filtering, Inference) successfully complete before deadline \(T^{\max}\).
  • Mean Effective Latency (\(\bar{L}\)): Average turnaround latency per completed task, including queuing delay, CPU execution time, and Air-to-Air transfer latency.
  • Coordination Communication Energy (\(E_{\text{coord}}\)): Cumulative radio transmission energy expended across the swarm on 802.11p consensus broadcast packets.
  • Task Fragmentation Ratio: Fraction of multi-stage workflows whose constituent stages were split across different physical UAVs.

FAQ & Troubleshooting

Q: Eclipse throws "Cannot find symbol: CloudSim" during build?

Ensure all JAR files in the jars/ directory are explicitly added to the project build path. In Eclipse: Right-click Project → Build Path → Configure Build Path → Libraries → Add JARs...

Q: OutOfMemoryError occurs during 3,000-task sweeps?

Allocate adequate heap space to the Java Virtual Machine by appending -Xmx4g (e.g. java -Xmx4g -cp ".;jars/*;bin" ...).

Q: How do I change the multiplier parameter \(\gamma\)?

Modify ProposedParams.DEP_BONUS_MULTIPLIER in ProposedParams.java or pass it as an override argument during experiment initialization.
